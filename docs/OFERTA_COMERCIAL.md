# Propuesta de entrega local por pago único

Alcance elegido por el usuario: una instalación independiente por negocio, sin mensualidad del software, dominio, hosting ni emisión fiscal incluidos. Precio de propuesta: **S/3,000 por negocio**, sujeto al alcance y al precio total acordados en la cotización. No es una garantía de ventas ni una cesión exclusiva del proyecto.

## Incluido para cotizar

- Sistema de catálogo/fotos/variantes, inventario y compras, POS/caja, clientes, crédito/abonos, pedidos, devoluciones, permisos e informes existentes.
- Una instalación Windows x64 local con PHP, PostgreSQL, dependencias y recursos compilados incluidos. No requiere Node ni Docker para operar esa entrega.
- Configuración de marca y una importación de hasta 200 productos desde una plantilla ya preparada por el cliente. Digitación, fotografía y limpieza de archivos ajenos se cotizan aparte.
- Una sesión de capacitación y manual de uso, configuración de respaldo diario y ensayo de restauración. El cliente aporta el destino de copia separado y custodia las claves.
- Acompañamiento y corrección de errores durante un plazo definido; propuesta de 60 días, pendiente de aceptación por escrito. Definir horario y límites de asistencia.
- Código y configuración de despliegue preparada para un servidor compatible con Laravel/PostgreSQL. El despliegue futuro se cotiza aparte después de elegir infraestructura; no se promete compatibilidad con cualquier hosting compartido.

## Exclusiones

Dominio, hosting, SMTP/entrega real de correos, almacenamiento externo, hardware, visitas, integración fiscal, pasarela bancaria, WhatsApp API y nuevas funcionalidades. Yape/BCP son registros manuales; los tickets son documentos internos. Las cantidades son enteras; elegir panadería o mecánica no incluye recetas/producción, peso fraccionario ni órdenes de taller. No se ofrecen usuarios, ventas, soporte ni actualizaciones ilimitados.

El código del proyecto ya es accesible en GitHub. La oferta cobra configuración, instalación, adaptación y servicio por negocio, conservando licencias de componentes de terceros. Definir expresamente si se entrega código y qué derechos adicionales se pactan; no prometer exclusividad sobre código ya publicado.

## Antes de aceptar la entrega

Mostrar una demostración con datos sintéticos, acordar equipos/usuarios/volumen/periféricos y límites, ejecutar la aceptación del equipo real y completar `ACTA_ENTREGA_CONFORMIDAD.md` sin casillas preaceptadas. Las pruebas del desarrollador no sustituyen la aceptación del cliente ni justifican declarar alojamiento público o integraciones ya activados.
