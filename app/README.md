# SAS SAN — aplicación

Consulte ../README.md para el inicio local y ../docs/PROGRESS.md para alcance y evidencia. El entorno nativo portátil está en ../.runtime; iniciar.ps1 conserva datos y claves. Docker permanece como alternativa cuando su disco esté sano. No publicar artisan serve ni copiar archivos .env a repositorios.

Fuente inicial: starter oficial Laravel Vue. Se mantienen Laravel, Vue, Inertia, Fortify y PostgreSQL. Los lockfiles están incluidos; no usar SQLite para validar aislamiento. Documentación de operación en ../docs/OPERACION.md y controles en ../docs/SECURITY.md.
